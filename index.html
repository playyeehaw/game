    <!-- Application Structure Plan:

         The app is designed as a vertical scrolling interactive dashboard, mimicking a series of wanted posters or saloon notices.

         1. Hero Section: High-level game stats (Players, Time, Age) for immediate context.

         2. "The Armory" (Components): Uses a Donut Chart to visualize the massive dice pool (50 dice), emphasizing the scale.

         3. "The Six Shooter" (Round Structure): Uses a Bar Chart to show the linear progression of target numbers across 6 rounds.

         4. "The Showdown" (Core Loop): An interactive tab system (Setup -> Draw -> Fire -> Win) allowing users to step through the mechanics at their own pace.

         5. "The Shootout" (Tie Breaker): A fully interactive JS simulation where users can "roll" dice to experience the high-card mechanic firsthand.

         This structure moves from abstract stats -> game components -> macro structure -> micro gameplay -> specific edge cases (tie-breaker), creating a logical learning curve.

    -->

   

    <!-- Visualization & Content Choices:

         1. Hero Stats -> Goal: Inform -> Big Number Cards -> Simple, high impact.

         2. Dice Pool -> Goal: Inform/Compare -> Chart.js Donut -> Shows the ratio of dice per player vs total pool (50). Justification: Emphasizes that "50 dice" is a lot.

         3. Round Progression -> Goal: Change -> Chart.js Bar -> Visualizes the rising Target Number (1-6) per round. Justification: Visual reinforcement of the "escalating" targets.

         4. Gameplay Loop -> Goal: Organize/Process -> Interactive Tabs (HTML/CSS/JS) -> Breaks down the chaos into 4 distinct steps. Justification: Text-heavy rules are harder to digest; steps are easier.

         5. Tie Breaker Sim -> Goal: Engage/Simulate -> JS Dice Roller -> Users click to roll 2 dice and see a winner. Justification: "Show, don't just tell" the high-card mechanic.

         CONFIRMATION: NO SVG graphics used. NO Mermaid JS used.

    -->

        const diceChars = ['⚀', '⚁', '⚂', '⚃', '⚄', '⚅'];

       

        function rollDuel() {

            const die1El = document.getElementById('die1');

            const die2El = document.getElementById('die2');

            const resultEl = document.getElementById('duel-result');

            // Add shake effect

            die1El.classList.add('shake');

            die2El.classList.add('shake');

            resultEl.style.opacity = '0';

            // Wait for shake to simulate rolling time

            setTimeout(() => {

                die1El.classList.remove('shake');

                die2El.classList.remove('shake');

                // Generate random 1-6

                const val1 = Math.floor(Math.random() * 6) + 1;

                const val2 = Math.floor(Math.random() * 6) + 1;

                // Update Visuals

                die1El.innerText = diceChars[val1 - 1];

                die2El.innerText = diceChars[val2 - 1];

                // Determine Winner

                resultEl.style.opacity = '1';

                if (val1 > val2) {

                    resultEl.innerText = "YOU WIN THIS ROLL!";

                    resultEl.style.color = "#27ae60"; // Green for win

                } else if (val2 > val1) {

                    resultEl.innerText = "RIVAL WINS THIS ROLL!";

                    resultEl.style.color = "#c0392b"; // Red for loss

                } else {

                    resultEl.innerText = "DRAW - ROLL AGAIN!";

                    resultEl.style.color = "#f4e4bc"; // Parchment for tie

                }

            }, 500);

        }
